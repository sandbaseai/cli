# SandBase CLI support

Use the channel that best matches your request:

- **Setup and usage questions:** start a [GitHub Discussion](https://github.com/sandbaseai/cli/discussions).
- **Reproducible bugs:** use the [bug report form](https://github.com/sandbaseai/cli/issues/new?template=bug-report.yml).
- **Client or workflow proposals:** use the [feature request form](https://github.com/sandbaseai/cli/issues/new?template=feature-request.yml).
- **Security concerns:** follow the private reporting instructions in the [security policy](SECURITY.md).

Before requesting help, run:

```sh
npx -y @sandbaseai/cli@latest doctor
```

Include the CLI version, client and version, operating system, exact command, and sanitized output. Never post API keys, access tokens, credentials, or private configuration.

Support is provided on a best-effort basis by project maintainers and contributors. Focused reports with reproducible steps are the fastest to diagnose.
