连接你已经在用的 AI 客户端。

交互式安装会检测目标客户端，并写入对应的 MCP 配置。

$ brew install sandbaseai/tap/sandbaseai-cli
$ sandbase catalog --json
$ sandbase connect

$ npx -y https://github.com/sandbaseai/cli/releases/download/v0.1.17/sandbaseai-cli-0.1.17.tgz connect

六个真实 MCP 工具，覆盖完整调用流程。

先发现，再检查，然后运行。

sandbase_discover
sandbase_inspect

查看参数、输出、价格和要求。

sandbase_run

执行选定的模型或 API。

sandbase_run_get

获取异步任务的最新结果。

sandbase_runs

查询最近运行与成本。

sandbase_account

查看账户余额与状态。
